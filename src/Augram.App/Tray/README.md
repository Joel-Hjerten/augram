# Tray

The tray icon (Windows) and the menu-bar item (macOS): Open · Enabled · Start at login · Sync now · Quit, the tooltip, and single versus double click. The behaviour, with Joel's decisions, is below; the version and channel, start at login, the hidden launch and one Augram at a time are in `Hosting/README.md`.

## Which type for which job

| Job | Use | Notes |
|---|---|---|
| The tray as a whole (menu, tooltip, click handling) | `AppTray` | Over the platform's `ITrayHost`; reads `Hosting/Startup/AppState` for the flags. |
| The platform item | `ITrayHost`: `AvaloniaTrayHost` (Windows, Linux), `MacTrayHost` (macOS, Augram's own `NSStatusItem`) | Each raises `Clicked` once per left click. |
| Single click (toggle) versus double click (open) | `ClickDiscriminator` + `ClickKind` | 300 ms window, a `DispatcherTimer`. |
| The icons | `TrayIconSet` + `TrayIconKind` | Generated by `tools/IconTool`. |
| The menu as plain data (the macOS item shows it) | `TrayMenuEntries` | |
| Sync now and the tooltip's last sync | `SyncTrayItem` | Follows `SyncService.Changed` through its marshal (`Hosting/UiThread.Post` unless a test passes one). |

## Behaviour (F7)

The item is the platform's `ITrayHost` (2026-10-09): `AvaloniaTrayHost` (Avalonia's `TrayIcon`) on Windows and Linux, `MacTrayHost` on macOS, which is Augram's own `NSStatusItem` (`Platform.MacOS/MacStatusItem`) because Avalonia's menu-bar item opens its menu on every click and reports none; there the menu opens on a right click or a Control-click and shows the same `NativeMenu`, read afresh each time it opens (`TrayMenuEntries`). Each host raises `Clicked` once per left click, so single versus double click is reconstructed by `ClickDiscriminator` with a `DispatcherTimer` : a single click toggles `AppState.Enabled` once the 300 ms window has passed (Joel, 2026-10-09; not the system's 500 ms), but the icon already shows the toggled state from the first click (`AppTray._preview`, snappier); a second click inside it opens the main window and puts the icon back. A click right after a double is swallowed (Windows can send up, double, up). The menu has Open · Enabled (checkable) · Start at login (checkable; disabled in a Dev build) · Sync now (only while a sync repository is set; `SyncTrayItem`) · Quit, and the tooltip starts with the build's name and ends with the last sync ("Augram (Dev) 0.5.1 (enabled) · synced 14:32", `AppTray.ToolTipFor`); while a "disable while focused" excluded app has focus it says "Augram 0.5.1 (paused: VMware is focused)" instead of "(enabled)" (`EnginePauseState`, see `ViewModels/Ignored/README.md`); the icon does not change. Diagnostics: `CompositionRoot` wires `ChannelEventLog` → `InMemorySink` (Diagnostics › Log) + `RollingFileSink` (`<config>/logs`), `HealthRegistry` (Diagnostics › Health, refreshed every second) and `RecognitionLog` (Diagnostics › Recognition); the engine host registers there in step 4b.
