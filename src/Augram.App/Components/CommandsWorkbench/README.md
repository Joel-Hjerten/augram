# CommandsWorkbench

The layout of a Commands sub-tab: the tree (`PART_Tree`) beside the selected command's header (`PART_Header`) and step list (`PART_Steps`, its card's first row the "Steps for" `StepSideBar`, `PART_StepSide`, whose `Item` it sets to `SelectedCommand` in code since the row is the list's content, and whose requests it relays as the header's), or the side panel's form (an app group, a hold remap, a category). It passes the view model's data down (`SelectedCommand` is a `CommandHeaderItem`; its step refusals go to the step list; `SearchText` two-way to the tree's search box, plan 0009) and forwards the parts' events up. No rules of its own.
