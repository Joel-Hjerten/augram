# GesturePicker

The Select Gesture picker (F3): `GesturePicker` is the lookless content (every gesture as a `GestureTile`, single selection, No gesture / New gesture… / OK / Cancel); its template puts it in the `Dialogs/DialogShell` (No Gesture and New Gesture… as the shell's `LeadingButtons`); `GesturePickerPresenter` shows it in a `GesturePickerWindow` (a `DialogWindow`: Escape closes it, which answers Cancel once) over the main window, follows the library while open and opens training for New gesture…; `IGesturePickerPresenter` and `GesturePickerResult` are what the Commands view model sees.
