# GesturePicker

The Select Gesture picker (F3): `GesturePicker` is the lookless content (every gesture as a `GestureTile`, single selection, No gesture / New gesture… / OK / Cancel); `GesturePickerPresenter` shows it in a `GesturePickerWindow` over the main window, follows the library while open and opens training for New gesture…; `IGesturePickerPresenter` and `GesturePickerResult` are what the Commands view model sees.
