# GesturePicker

The Select Gesture picker (F3): `GesturePicker` is the lookless content (every gesture as a `GestureTile`, single selection, No gesture / New gesture… / OK / Cancel); its template puts it in the `Dialogs/DialogShell` (No Gesture and New Gesture… as the shell's `LeadingButtons`); `GesturePickerPresenter` shows it in a `GesturePickerWindow` (a `DialogWindow`: Escape closes it, which answers Cancel once) over the main window, follows the library while open, narrows the tiles by the picker's search box (`PART_Search` above the tiles, plan 0009: `GesturePickerPresenter.Tiles` puts the gestures whose name starts with the text first, the selection kept by id across refilters; `EmptyText` while nothing is left) and opens training for New gesture…; `IGesturePickerPresenter` and `GesturePickerResult` are what the Commands view model sees.
