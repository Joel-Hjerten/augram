# GestureGrid

The Gestures tab's grid (F3, F4, F5a): `Tiles` (`GestureTileItem`, sorted by the host) in, one `GestureGridActionEventArgs` out. Selecting a tile marks its duplicates (A7) with their score; selection survives a rebuild by id; right-click selects; a double click redraws. The toolbar's search box (`PART_Search`, a `SearchBox/SearchBox` two-way bound to `SearchText`, plan 0009) narrows the tiles through the host; `EmptyText` says "No gestures match 'xyz'" while nothing is left; the find key (`GestureGridAction.Find`) focuses the box, where the edit keys stand down.

| Type | Job |
|---|---|
| `GestureTile` | A tile on `ListEditing/ItemRow` (rename in place; no active box): glyph, name, `:duplicate`, `:partner`. Also the gesture picker's tile. |
| `GestureGridMenu` | The menu table over `ListEditing/ActionMenu`; keys from `EditKeymap` (F2 or Enter renames on Windows, Return on macOS). |
| `GestureTileItem`, `GesturePartner` | Tile data; `From(gesture, pairs)` picks the partners (it stays here: the gesture picker's presenter, in Components, builds tiles too). |

## Gestures tab (F3, F4, F5a, A7; plan 0001 M1 step 7)

`GesturesModule.Register(services)` is the tab's slice of the composition root (training session, presenters, `GesturesViewModel`); `GesturesModule.NavEntry(services)` is its tab entry. It expects `GestureLibrary`, `SettingsStore` and `IEventLog` to be registered and falls back to the starter set and default recognition options when they are not (tests, gallery).

- **GestureGlyph** draws a gesture's first sample: `GlyphGeometry.Normalise` fits the bounding box into the tile on the longer axis (aspect ratio kept, centred inside `Padding`), the polyline gets round caps and an arrowhead on the last segment; `:inactive` greys it through the theme. The template draws it with `GlyphStroke`: from a shaded start (`Brush.GlyphStart`) to the end colour (`Brush.Glyph`) by arc length; the running app sets both from Options › Appearance › Trail › Colour (`Themes/AppearanceLink`; the start is `GlyphColours.StartFor`: darker, hue-shifted towards blue-violet the shorter way round, so yellow starts amber, cyan blue), inactive pictures stay grey, so where a stroke starts and which way it runs reads along its whole length (Joel, 2026-10-08; pictures only, never the live trail or the draw area). The geometry is rebuilt only when the points or the size change.
- **GestureGrid** is presentational: `Tiles` (sorted by the view model, each carrying its A7 duplicates), `CanUndo`/`CanRedo`, `Message` in; one `ActionRequested` event out carrying a `GestureGridAction` (New, Redraw, Rename, Delete, KeepThis, Import, Export, Undo, Redo), the selected tile and, for Rename, the new name. Toolbar buttons (Add new gesture…, Import from StrokesPlus.net…, Export… (the export dialog with gestures only preselected, plan 0003; `GesturesViewModel` shows its outcome on the message line), Undo, Redo), the right-click menu (New, Redraw, Rename, Delete and, on a tile with duplicates, "Keep this, delete its duplicates"), the keymap (`EditKeymap`: F2 or Enter on Windows / Return on macOS to rename (Q11, 2026-10-11: Enter as on the Commands tab), Ctrl/Cmd+N, Delete, Ctrl/Cmd+Z, Ctrl+Y / Cmd+Shift+Z) and double-click (Redraw) all end in that event. Rename edits in place inside `GestureTile`; the list's key bindings stand down while an editor has focus. Delete asks nothing; Undo brings it back (A9). Active is per command, not per gesture (F3, 2026-10-07), so a tile has no toggle; a gesture no command uses is drawn greyed in M2.
- **GesturesViewModel** turns actions into `GestureLibrary` calls and shows the rule message (`GestureValidationException`) when one is rejected. Its `SearchText` (plan 0009, UI-only, cleared when the main window hides) narrows the tiles by name (`SearchQuery`); partners stay by id, so a hidden partner is simply not lit. Duplicates (A7) come from `Core.Recognition.ConfusionCheck` at `DuplicateCutOff` (90), recomputed 200 ms after the last library change: a tile with duplicates is outlined in red, selecting it lights its partners up with the score (the frame only changes colour, never thickness, so the grid never shifts), and "Keep this, delete its duplicates" removes them in one undo step. There is no diagnostic text line under the grid.
