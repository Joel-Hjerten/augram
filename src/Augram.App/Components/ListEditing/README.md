# ListEditing

The pieces every editable list shares (the contract is in `../README.md`). One home each.

| Type | Job |
|---|---|
| `ItemRow` | Base of every list row (`SectionRow`, `CommandRow`, `StepRow`, `MasterRow`, `GestureTile`): the one in-place rename editor (`PART_NameEditor`; `BeginEdit`, Enter or leaving commits, Escape reverts, an unchanged name raises nothing, a commit on leave is posted so a click elsewhere selects first), the active box (`PART_Active`, raised only for a user click), `:editing` / `:inactive`, and the double-click rename rule (`IsRenameClick`, `RenamesAt`). A row without `PART_Active` (a tile) simply has no box; `CanRename` false turns rename off. |
| `ActionMenu<TAction>` | A list's context menu from its entry table (`Build`, each entry's `Tag` is its action; `Entries` for the list's `Refresh` rules) and its key bindings (`BindKeys`: a null key is skipped; `canExecute` must say no while a name editor or a form has focus). |
| `RowListHost` | The plumbing around a list's `ListBox`, owned by each list as a field (composition, not a base class): `Attach` takes the template's list and its user-selection callback (and, for tiles, the double-tap action); `SelectQuietly` applies the host's selection without echoing it back as Select; `Replace` swaps the rows quietly, applies the selection, and gives the focus back to the selected row's replacement after a rebuild (`FocusAfterRebuild`: `None` for the step list, `SelectedRow` for MasterDetail, `SelectedRowUnlessSettled` for the command tree); `SelectOnRightPress`; `RenameOnDoubleClick` (the press-count rule, `ItemRow.IsRenameClick`, posted so the first click's rebuild settles); `BeginRename`/`RenameSelected`; `KeysEnabled` (the key bindings' `canExecute`) and `AnyEditing(rows)`. Used by `CommandTree`, `MasterDetail`, `StepList`, `GestureGrid`, `GesturePicker`. What stays in each list: finding a row by the host's id, what a user selection raises, row reuse (the step list), the grids' remembered id. |
| `EditKeymap` | The one per-platform keymap (`Current`; tests build the other): rename F2, and Enter as a second key, on Windows; Return on macOS (Q11, 2026-10-11, the Gestures tab included); New, Copy, Paste, Duplicate, Delete, Undo, Redo, Find (the search box, plan 0009) with Ctrl or Cmd. View models name its keys in their messages. |

Each list keeps its own `…Menu` (table and `Allows`/`Refresh` rules) and action enum; a list with a search box counts the box being typed in as editing (`SearchBox.IsTyping`), so its keys stand down there too. Do not bind a key, build a `MenuItem` or handle a rename key outside these types, and do not handle a list's `SelectionChanged`, `DoubleTapped` or a right press outside `RowListHost`, or keep an `_applying` flag in a list.
