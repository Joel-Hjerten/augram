# MasterDetail

A list beside a form (the Exclusions tab): `Items` (`MasterItem`) in, one `MasterDetailActionEventArgs` out, the host's form in the detail slot. Looks and keys follow the Commands tab: rows are `MasterRow` on `ListEditing/ItemRow` (rename in place), the menu is `MasterDetailMenu` over `ListEditing/ActionMenu` with `EditKeymap`'s keys; `MoveLabel` adds the move to the host's other list.
