# Threading

The thread table for the engine (hook thread, engine worker, command executor, ignore-list watch, tick timer, health poll, log drain) and what each may and may not do lives in [src/Augram.Engine/README.md](../../src/Augram.Engine/README.md), next to the code that enforces it. Rules in one line: the hook thread only translates, decides suppression from a shadow (the gesture shadow, the key record, and the hold remap shadow, asked first), and enqueues one message per decision; the engine worker is the only caller of the capture and hold remap state machines and the only injector of a press's own input and of a hold remap's outputs, taps, replays and re-posted drags (macOS: while a hold remap holds a button output the hook swallows moves too and the worker re-posts them) (the command executor injects only for the steps it runs); the platforms raise system events (a new foreground among them) on the UI thread and the engine only flags and wakes there; nothing in Engine touches the UI thread.
