# Augram.Platform.Windows.Tests

xunit tests for `Augram.Platform.Windows`. The window system is split into pure rules (`FullScreenRule`, `DesktopRule`, `UwpHostRule`, `ActivationPolicy`) and two classes that consume a native facade (`WindowIdentityReader`, `ForegroundActivator`); all of those are tested here against `FakeWin32`, a scripted in-memory window tree. One integration test (`Win32WindowSystemTests.WindowAt_Cursor_*`) calls real Win32 at the cursor position and only asserts "no exception, sane or null"; it returns early when `Environment.UserInteractive` is false. `Startup/` runs `RunKeyStartupRegistration` over `FakeStartupRegistry` (fresh, outdated command, switched off and back on in Task Manager, on and off) and `StartupApprovedRule` over Task Manager's bytes; `Win32StartupRegistryTests` checks the real registry facade under a throwaway `HKCU\Software\AugramTest-<guid>` key, deleted in `finally` (skipped when not interactive). **No test writes the real Run or StartupApproved key** (a test must never register a login item); `Input/` covers the cursor probe and the `SystemEvents` mapping. `Launch/` tests `ShellStartInfo` and drives `Win32ProcessLauncher` through a fake start delegate (started, declined UAC prompt, Win32 errors, the STA thread, a late answer); no test starts a process. `Clipboard/` drives `Win32Clipboard` through scripted Open/Empty/Close calls and a recorded wait (cleared, held for a while, held for good, a failed empty still closes); no test touches the real clipboard. `Display/` runs `Win32DisplayModes` against `FakeWin32Displays` (scripted devices, settings and CCD targets; the change and HDR calls are only recorded) and pins the display interop struct sizes; **no test may change a real display mode or HDR**.

**May reference:** `Augram.Platform.Windows` (internals via `InternalsVisibleTo`), `Augram.Core`, xunit. Runs on the Windows CI runner.
